# EventVerse 贡献者许可协议（CLA）

> 通过向本仓库提交 Pull Request，你同意以下条款。目的：保持 AGPL-3.0 开源的同时，
> 保留项目方（著作权持有人）以商业双许可（AGPL + 商业授权）方式发布的选择权（设计方案 §10）。

1. **贡献授予**：你在 Apache-2.0 与 AGPL-3.0 双重条款下，将你的贡献的永久、全球、免版税、
   不可撤销的版权许可授予项目方；项目方可将其用于本项目的任何许可证组合（包括未来变更或附加商业许可）。
2. **专利授权**：你同时授予项目方与你贡献相关的专利使用许可（防御性终止：若你对项目发起专利诉讼则自动终止）。
3. **原创声明**：你声明该贡献为你原创，或你有权按本协议授予上述许可；不含任何未经许可的第三方代码
   （若包含第三方代码，须在 PR 中显著标注来源与许可证）。
4. **不保证**：贡献按"现状"提供，不附带任何明示或默示的保证。
5. **保留权利**：你保留对你贡献的一切权利；本协议仅授予项目方上述许可，不是版权转让。

——签署方式：提交 PR 即视为接受本 CLA（以 PR 记录与 Git 提交身份为准）。
